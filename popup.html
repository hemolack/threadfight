Thread Fight

Before your first fight

When you start a fight, Thread Fight reads the comments currently showing on the post you pick and sends their text to the AI provider you set up in Settings (Anthropic, OpenAI, or your own server), so it can referee the argument.

  • Names are replaced with “User 1, User 2…” before anything is sent.
  • Nothing is sent to the makers of Thread Fight. There is no Thread Fight server.
  • Your API key and settings stay in this browser.
