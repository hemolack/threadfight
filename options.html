Your key is stored in this browser's extension storage and is sent only to the provider above. Commenter names are replaced with “User 1, User 2…” before the thread is sent to the model, and the video shows only Red and Blue. There is no Thread Fight server. Privacy policy

Local servers: Ollama blocks requests from browser extensions unless you start it with OLLAMA_ORIGINS="chrome-extension://*". LM Studio needs “Enable CORS” turned on. If the server is on another machine, Chrome asks you to allow that address when you click Save.
